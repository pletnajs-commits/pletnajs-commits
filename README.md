### Hi, I'm Pletnajs 👋

Self-taught builder from Czechia. I make small, privacy-first apps that solve one real problem each — mostly native iOS in SwiftUI, plus a bit of Python and microcontrollers.

**Things I'm working on**

| Project | What it is | Stack |
|---|---|---|
| [**HolterNotes**](https://github.com/pletnajs-commits/HolterNote) | Activity diary for people wearing a Holter monitor. One tap or a dictated note, then a clean PDF/CSV for the doctor. Everything stays on the phone. | SwiftUI · SwiftData · WidgetKit · Speech |
| [**Prefronta**](https://github.com/pletnajs-commits/Prefronta) | Speak a plan, get it in your calendar. iPhone + Mac. | SwiftUI · EventKit · Mac Catalyst |
| [**DiktatHID**](https://github.com/pletnajs-commits/DiktatHID) | ESP32-S3 that shows up as a USB keyboard and types what you dictate — no software on the target PC. | ESP32-S3 · C · ESP-IDF · Swift |
| [**Octomilka**](https://github.com/pletnajs-commits/Octomilka) | Simulating the fruit-fly connectome (FlyWire) in Brian2 and letting it walk and fly in a 3D world. | Python · Brian2 · Three.js |
| [**Mapa filozofie**](https://github.com/pletnajs-commits/MapaFilozofie) / [**Mapa Pythonu**](https://github.com/pletnajs-commits/MapaPythonu) | Interactive, collapsible maps for learning philosophy and Python patterns. | HTML · JS |

Each repo shows what the project does and how it looks. The source code stays private.
