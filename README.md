### Hi, I'm Pletnajs 👋

Self-taught builder from Czechia. I make small, privacy-first apps that solve one real problem each — mostly native iOS in SwiftUI, plus a bit of Python and microcontrollers.

**Things I'm working on**

| Project | What it is | Stack |
|---|---|---|
| [**HolterNotes**](https://github.com/pletnajs-commits/HolterNote) | Activity diary for people wearing a Holter monitor. One tap or a dictated note, then a clean PDF/CSV for the doctor. Everything stays on the phone. | SwiftUI · SwiftData · WidgetKit · Speech |
| **Prefronta** | Speak a plan, get it in your calendar. iPhone + Mac. | SwiftUI · EventKit · Mac Catalyst |
| **DiktatHID** | ESP32-S3 that shows up as a USB keyboard and types what you dictate — no software on the target PC. | ESP32 · C++ |
| **Octomilka** | Simulating the fruit-fly connectome (FlyWire) in Brian2 and letting it walk and fly in a 3D world. | Python · Brian2 · Three.js |
| **Mapa filozofie** / **Mapa Pythonu** | Interactive, collapsible maps for learning philosophy and Python patterns. | HTML · JS |

Most of these are not public yet — they'll land here as they get ready.
